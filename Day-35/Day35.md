# 🧩 Day 35 — Prompt Puzzle: Master AI Prompting Through Play

## 📌 Project Overview

Today I built **Prompt Puzzle**, an interactive educational game that teaches the fundamentals of **AI Prompt Engineering** through engaging challenges instead of traditional tutorials.

Rather than simply explaining prompt writing concepts, this simulator allows users to **practice, analyze, and improve prompts** using real-world scenarios.

The application works completely offline as a **single HTML file** and provides an immersive experience with live scoring, drag-and-drop gameplay, and personalized feedback.

---

# 🎯 Objectives

- Learn Prompt Engineering interactively
- Understand why some prompts perform better than others
- Compare weak vs optimized prompts
- Improve prompt writing through practical exercises
- Analyze AI outputs generated by different prompt styles

---

# 🚀 Features

### 🎮 Interactive Prompt Puzzle

Players complete multiple prompt engineering challenges using randomized scenarios.

Challenge Types:

- Build the Prompt
- Clean the Prompt
- Choose the Best Prompt

---

### 🧩 Drag & Drop Gameplay

Interactive prompt blocks allow users to construct prompts by arranging the correct components.

---

### 📚 Scenario Generator

Every playthrough generates multiple unique prompt engineering scenarios based on:

- Selected Domain
- Difficulty Level

---

### ⚡ Prompt Comparison

Every scenario demonstrates:

- Weak Prompt
- Optimized Prompt
- Over-Engineered Prompt

along with their AI outputs.

---

### 📈 Live Performance Tracking

The simulator continuously measures:

- Prompt Score
- Accuracy
- Time Taken
- Total Moves
- Wrong Placements
- Hints Used
- Optimization Bonus

---

### 🧬 Prompt DNA Analysis

At the end of the game users receive:

- Prompt DNA
- Personalized Feedback
- Next Milestone
- AI Optimized Prompt
- Overall Rating
