## Market Insights

* SQL remains the most requested skill across Data Analyst roles.
* Power BI continues to be highly valued in Business Intelligence positions.
* Delhi NCR currently shows strong demand for entry-level analytics professionals.
* Many companies prefer internship-to-full-time hiring pipelines for freshers.

## Key Learnings

1. Power BI and DAX provide a strong foundation for Data Analytics roles.
2. SQL is the biggest skill gap that must be addressed immediately.

4. GitHub portfolios significantly strengthen fresher applications.
5. Continuous learning and skill-building directly improve job-market fit.
