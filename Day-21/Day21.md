# Day 21 – Build a Digital Privacy & Footprint Intelligence Dashboard using Claude AI

## Objective

The objective of Day 21 was to build an AI-powered Digital Privacy & Footprint Intelligence Dashboard using Claude AI.

The goal was to understand how everyday digital services contribute to online exposure, data collection patterns, and privacy risks.

This project focused on:

- Privacy analytics
- Cybersecurity awareness
- Data exposure analysis
- AI-generated dashboards
- Responsible data interpretation

---

# Tool Used

## Claude AI

Used Claude to generate a complete interactive HTML dashboard.

---

# Project Overview

Created a premium cybersecurity-style dashboard that analyzes a sample digital footprint dataset.

The dashboard evaluates:

- Digital Footprint Score
- Privacy Score
- Exposure Heatmap
- Company Exposure Ranking
- Data Collection Matrix
- Risk Radar
- Digital Twin Profile
- Privacy Improvement Plan

---

The analysis was performed using a sample dataset containing digital services:

Applications:
