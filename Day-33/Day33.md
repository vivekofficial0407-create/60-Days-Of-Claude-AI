# 📰 Day 33 - Media Integrity Analyzer

## 📌 Project Overview

Today I built **Media Integrity Analyzer**, an interactive web application designed to teach media literacy through hands-on analysis instead of passive reading.

The simulator helps users recognize misleading headlines, emotional manipulation, and biased content while learning how news and social media influence public perception.

Everything is contained in a **single HTML file** built using Vanilla JavaScript, HTML, and CSS.

---

# 🎯 Objectives

- Understand media literacy fundamentals
- Detect misleading headlines
- Analyze emotional manipulation techniques
- Improve critical thinking before consuming online content
- Learn how media influences audiences

---

### 📰 Headline Detective
- Random fictional news headlines

### 📊 Live Integrity Metrics

- Headline Accuracy
- Source Reliability
- Emotional Manipulation
- Audience Targeting

Metrics update dynamically throughout the experience.

### 📈 Final Media Integrity Dashboard

Displays:

- Overall Media Integrity Score
- Biggest Red Flag
- User Learning Summary
- Practical Media Literacy Habits
- Replay with New Scenarios

---

# 💡 Key Learnings

- Headlines are often optimized for attention rather than accuracy.
- Emotional language can strongly influence perception.
- Media literacy requires questioning sources before sharing information.
- Rewriting sensational content into neutral language improves clarity.
- Interactive learning is an effective way to understand misinformation.
