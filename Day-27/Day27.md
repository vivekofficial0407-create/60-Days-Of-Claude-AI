# Day 27 - Build an Interactive Prior Authorization Story Simulator

## Overview

As part of the 60 Days of Claude AI Challenge, I built an interactive healthcare education application using Claude AI.

This project transforms a complex healthcare process — Prior Authorization — into a story-driven learning experience.

Instead of only showing workflow steps, this simulator teaches the process through a patient's journey.

---

# Project Name

## Prior Authorization Story Simulator

A healthcare education simulator where users follow Rahul's healthcare journey and understand how Prior Authorization works between:

- Patient
- Healthcare Provider
- Insurance Payer


---

# Objective

The goal was to create an interactive experience that explains:

- Why Prior Authorization exists
- How insurance review works
- Why documents matter
- How denials happen
- How appeals work
- How approvals are achieved


---

# Technology Used

- HTML
- Tailwind CSS
- Vanilla JavaScript
- Claude AI


---

# Main Features


## 1. Story-Based Learning

The simulator follows Rahul's journey:

Rahul:
A patient diagnosed with Rheumatoid Arthritis who requires Humira treatment.

Priya:
A healthcare operations specialist explaining each step.


---

# 2. Eight Interactive Chapters


## Scene 1 - Doctor Visit

Rahul visits City Medical Center.

Dr. Patel diagnoses Rheumatoid Arthritis and recommends Humira.

Learning:

Patients may require insurance approval before expensive treatments.


---

## Scene 2 - Insurance Roadblock

The Prior Authorization request moves:

Provider → PA Request → Payer

StarCare Health reviews the request.


---

## Scene 3 - Understanding Prior Authorization

Priya explains:

- What PA means
- Why insurance companies use it
- How delays can affect patients


---

## Scene 4 - Insurance Review

The simulator explains what payers evaluate:

- Eligibility
- Clinical documentation
- ICD-10 diagnosis match
- Step therapy history


---

## Scene 5 - Denial Scenario

The request gets denied because:

Missing step therapy documentation


The user learns:

A denial does not always mean rejection forever.

---

## Scene 6 - Appeal Process

The user learns about:

- Document collection
- Letter of Medical Necessity
- Formal appeal submission


---

## Scene 7 - Approval

The Prior Authorization gets approved.

The simulator explains:

- Authorization reference number
- Saved approval
- Future treatment process


---

## Scene 8 - Final Takeaways

The application shows two perspectives:

Patient perspective:

Understanding healthcare navigation.

System perspective:

Tracking:

- Denial rate
- Appeal rate
- Resolution time


---
