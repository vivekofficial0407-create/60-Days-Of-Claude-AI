# Day 20 – Build an AI-Powered Face Puzzle Game with Claude AI

## Objective

The goal of Day 20 was to build a complete AI-powered interactive web application using Claude AI.

I created a Face Puzzle Game where users can capture their own image through webcam and convert it into a playable puzzle experience.

This challenge focused on combining:

- AI-assisted development
- Front-end development
- Browser APIs
- User interaction design
- Game logic implementation

---

# Project Overview

## Application Name

AI Face Puzzle Game

## Technology Used

- HTML
- CSS
- JavaScript
- Web Camera API
- Canvas API
- Local Storage

---

# Features Implemented

## 1. Webcam Integration

The application uses browser camera access through:

getUserMedia()

Features:

- Live camera preview
- User photo capture
- Camera permission handling
- Retake photo option

---

## 2. Puzzle Generation System

After capturing the image:

Users can select difficulty:

- 3×3 Grid
- 4×4 Grid
- 5×5 Grid


The application:

- Splits image into puzzle pieces
- Randomly shuffles pieces
- Generates playable puzzle board
- Allows users to rearrange pieces

---

## 3. Drag and Touch Interaction

The game supports:

Desktop:
- Mouse drag and drop

Mobile:
- Touch interaction


Implemented:

- Tile movement
- Piece swapping
- Grid snapping
- Selected piece highlighting
- Correct position detection

---

## 4. Timer and Move Tracking

The application tracks:

- Total completion time
- Number of moves
- Correctly placed pieces

This creates a game-like experience with performance tracking.

---

## 5. Winning System

The game automatically detects completion.

After solving:

Displays:

- Final time
- Total moves
- Difficulty level


---

## 6. Leaderboard System

Implemented using:

localStorage

Stores:

- Best times
- Difficulty
- Moves
- Completion records

Users can view previous best performances.
