# 📄 Day 39 – PDF Splitter & Merger

## 🚀 Project Overview

**PDF Splitter & Merger** is a premium browser-based PDF utility built as part of the **60 Days of Claude AI Challenge**.

The application enables users to split and merge PDF documents entirely within the browser without uploading files to any external server. By combining modern frontend technologies with client-side PDF processing libraries, the project delivers a secure, responsive, and professional document management experience.

---

# 🎯 Objective

The objective of this project was to build a fully client-side PDF utility that allows users to:

* Split PDF documents in multiple ways
* Merge multiple PDF files into one
* Preview PDF pages before processing
* Perform all operations locally for enhanced privacy
* Deliver a polished commercial-grade user experience

---

# ⚙️ How It Works

### PDF Splitting

1. Upload a PDF file.
2. The application reads the document locally.
3. Page thumbnails are generated.
4. Choose a splitting method.
5. Preview the resulting files.
6. Generate and download the output.

---

### PDF Merging

1. Upload multiple PDF files.
2. Preview uploaded documents.
3. Rearrange files using drag-and-drop.
4. Review total pages and estimated output.
5. Merge the PDFs.
6. Download the merged document.

---

# 🔒 Privacy

One of the strongest aspects of this project is privacy.

* No files are uploaded to any server.
* All processing happens entirely inside the browser.
* User documents remain on the local machine.
* No backend services are required.
