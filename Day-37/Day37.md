# 🚀 Day 37 – Task Compass
### Learn How Work Flows Through Real Organizations

## 📌 Overview

Today's challenge was to build **Task Compass**, an interactive workplace simulation designed to teach how work moves through organizations. Instead of testing job titles, the application focuses on helping users understand **ownership, delegation, collaboration, escalation, and workflow management** through realistic business scenarios.

The application was built as a **single offline HTML file** using **HTML, CSS, and Vanilla JavaScript**, ensuring it runs locally without any external dependencies.

---

# 🎯 Objective

The goal of this project was to help users think like managers by understanding:

- Who owns a task
- Which teams assist
- How work flows between departments
- Why collaboration matters
- How organizations solve complex problems together

---

# 🛠 Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Drag & Drop API
- Responsive Design
- Glassmorphism UI

---

# 🎮 Application Flow

## Stage 1 — Who Owns This?

Users are presented with realistic workplace situations and must identify the primary owner responsible for resolving the issue.

Examples include:

- Payment failures
- Customer complaints
- Product bugs
- Operational issues

Instead of simply marking answers as correct or incorrect, the application explains:

- Primary owner
- Why they own the task
- Supporting roles involved

---

## Stage 2 — Task Routing

Players organize the complete workflow by arranging different departments in the correct sequence.

Example:

Customer Support → QA → Backend → Product Manager → Customer

After submission, the workflow is animated to demonstrate how tasks move across teams in real organizations.

---

## Stage 3 — Collaboration Challenge

Larger business situations require collaboration rather than individual ownership.

Examples:

- Customer satisfaction drops
- Product delays
- Sales surge
- Negative public reviews

Users assign multiple departments and receive detailed explanations about communication flow and teamwork.

---

# 📊 Performance Report

Instead of traditional scores, the simulator evaluates understanding across four core workplace skills:

- Ownership
- Delegation
- Collaboration
- Workflow Thinking

A visual chart summarizes the user's organizational thinking profile.
