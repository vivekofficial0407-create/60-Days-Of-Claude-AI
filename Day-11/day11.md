# Day 11 – ATS Resume Optimizer & Resume Generator

## Overview

On Day 11 of the 60 Days Claude AI Challenge, I used AI to analyze my resume against a target Data Analyst Internship Job Description and improve ATS compatibility.

## Task Completed

* Uploaded my existing resume.
* Provided a target Data Analyst Internship Job Description.
* Performed ATS analysis.
* Identified keyword and skill gaps.
* Generated an ATS-optimized resume.
* Compared the original and optimized versions.

## ATS Analysis Results

* ATS Match Score: 82/100
* Improved from approximately 58/100 after optimization.

### Keywords Added

* Data Cleaning
* Exploratory Data Analysis
* Business Intelligence
* Reporting
* Trend Analysis
* Insights Generation
* Data-Driven Decision Making
* Cross-Functional Collaboration

### Identified Gaps

* SQL
* Tableau
* Statistics Coursework

## Key Learnings

* ATS systems prioritize relevant keywords and role-specific terminology.
* Resume content should align with the target job description.
* Strong project descriptions improve ATS performance significantly.
* AI can optimize resume structure while maintaining factual accuracy.
