# Day 17 – AI-Powered Vehicle Cost & Fuel Analysis Dashboard

## Challenge Objective

Build an AI-powered dashboard that analyzes vehicle ownership costs, fuel efficiency, maintenance expenses, environmental impact, and fuel economics using a CSV dataset and Claude AI.

---

## Task Completed

Using Claude AI, I generated a complete HTML dashboard that visualizes:

- Vehicle running cost analysis
- Fuel comparison metrics
- CO₂ emission analysis
- Maintenance cost trends
- Vehicle age impact
- E85 fuel economics
- Monthly ownership estimates

---

## Key Insights

### Petrol

- Reliable fuel availability
- Balanced performance
- Moderate running costs

### Diesel

- Efficient for long-distance travel
- Lower running cost than petrol
- Higher maintenance requirements

### CNG

- Lowest running cost among combustion fuels
- Environment friendly
- Limited infrastructure availability

### E85

- Lower pump price
- Mileage penalty affects actual savings
- Requires break-even analysis

### EV

- Lowest running cost overall
- Lowest emissions
- Higher initial investment

## Major Findings

### Cost per KM

### E85 Analysis

- Pump Saving: 30.6%
- Mileage Penalty: 20%
- Running Cost Penalty: 5.4%
- Break-Even Price: ₹79.5/L
- E85 Score: 4.6/10
