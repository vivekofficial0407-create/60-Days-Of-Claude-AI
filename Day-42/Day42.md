# 💰 Day 42 – Personal Financial Command Center

## 🚀 Project Overview

**Personal Financial Command Center** is an AI-inspired personal finance dashboard built as part of the **60 Days of Claude AI Challenge**.

Designed specifically for students, this application goes beyond traditional expense tracking by providing a complete financial overview through interactive dashboards, budgeting tools, savings planning, financial health analysis, AI-driven insights, and scenario-based planning.

The entire application runs directly in the browser with no backend dependencies, offering a responsive, privacy-friendly, and modern financial management experience.

---

# 🎯 Project Objective

Managing personal finances is often overwhelming, especially for students balancing academic expenses, hostel life, internships, and future career goals.

The objective of this project was to create a financial command center that enables users to:

- Understand their financial health at a glance
- Track income and expenses
- Build sustainable saving habits
- Visualize financial trends
- Simulate future financial scenarios
- Receive intelligent financial recommendations
- Plan smarter financial decisions

# ⚙️ How It Works

1. Select your financial profile.
2. Enter income, expenses, savings, and goals.
3. Review the Financial Health Score.
4. Explore AI-generated recommendations.
5. Run "What-if" financial simulations.
6. Track progress over time.
7. Generate a printable financial report.
