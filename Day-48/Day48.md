# Day 48 - The Verdict Engine
## AI-Powered Decision Comparison Platform

### 📌 Challenge Overview

Day 48 focused on building **The Verdict Engine**, a premium AI-powered decision comparison platform that helps users make confident choices by comparing multiple options using verified research, measurable criteria, adjustable priorities, and transparent citations.

Instead of relying on opinions or static rankings, the application dynamically recalculates results based on user-defined weights while displaying the research sources behind every comparison.

---

# 🎯 Objective

Develop a premium single-page web application that:

- Compares multiple real-world options
- Uses verified research and citations
- Allows users to prioritize decision criteria
- Updates rankings dynamically
- Explains how conclusions were reached
- Maintains complete transparency through source references

---

# 🚀 Features

## 📊 Interactive Comparison Dashboard

The application provides a modern comparison interface where users can evaluate multiple options side-by-side using measurable criteria.

---

## ⚖️ Dynamic Weight Adjustment

Users can personalize the comparison by assigning different importance levels to criteria such as:

- Performance
- Price
- Battery Life
- Build Quality
- Display
- Portability
- AI/ML Capability
- Value for Money

Rankings update instantly based on the selected priorities.

---

## 📈 Live Ranking Engine

Instead of fixed scores, the application calculates rankings dynamically using weighted criteria, allowing users to explore different decision scenarios.

---

## 🔍 Research-Based Decision Making

Every comparison is supported by cited information collected from reliable sources.

The application:

- Displays citations
- Lists research references
- Highlights estimated values
- Differentiates verified data from placeholders

---

## 📚 Sources Panel

A dedicated Sources section displays every reference used throughout the comparison, helping users understand where each data point originated.

---

## 🧠 Research Transparency

A collapsible **"How This Was Researched"** section explains:

- Research methodology
- Data collection process
- Conflicting sources
- Resolution strategy
- Confidence level
